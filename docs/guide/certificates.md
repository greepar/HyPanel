# TLS 证书

Hysteria2 服务需要一张 TLS 证书。在“设置 → TLS 证书”里添加，然后在服务里选择。支持三种方式：

## 手动上传

粘贴证书（PEM，含完整证书链）和私钥。适合临时使用或自签证书；自签证书会在订阅里自动固定指纹。

## 路径映射

填写**面板所在主机**上证书和私钥文件的路径，比如由 Lucky、acme.sh、certbot 自动续签的文件。

- 添加时会立即读取并校验，显示“有效期至”；
- 之后每分钟检查一次，文件更新后自动重新下发到所有使用它的节点；
- 读取失败会在证书列表里用红字提示原因（例如权限不足）。

::: tip
面板进程以 `hypanel` 用户运行，请确保它对证书文件有读权限。
:::

## ACME 自动签发

填写域名，面板会自动申请并在到期前续期。可以使用 Cloudflare DNS 验证（需要一个有 Zone.DNS 编辑权限的 API Token），
适合签发通配符证书。

## 通配符证书

使用 `*.example.com` 这样的通配符证书时，面板会按节点名自动生成具体的 SNI（例如节点 `uk` 使用 `uk.example.com`）。
请确保对应的域名解析到节点 IP，或在服务的“连接地址”里自定义 SNI。
