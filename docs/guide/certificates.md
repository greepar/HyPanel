# TLS 证书

Hysteria 2 和 AnyTLS 服务需要一张 TLS 证书。在左侧“证书”页添加，然后在服务里选择。支持三种方式：

## 手动上传

粘贴证书（PEM，含完整证书链）和私钥。适合临时使用或自签证书；自签证书会在订阅里自动固定指纹。

## 路径映射

填写**面板所在主机**上证书和私钥文件的路径，比如由 Lucky、acme.sh、certbot 自动续签的文件。

- 添加时会立即读取并校验，显示“有效期至”；
- 之后每分钟检查一次，文件更新后自动重新下发到所有使用它的节点；
- 读取失败会在证书列表里用红字提示原因（例如权限不足）。

::: tip
面板进程以 `hypanel` 用户运行，请确保它对证书文件有读权限。
:::

## ACME 自动签发

填写域名和邮箱，**面板**向 Let's Encrypt 申请，签发后像上传的证书一样下发给所有使用它的服务，任何内核（Hysteria 官方、Xray、Mihomo）都能用。
到期前 30 天自动续签；失败时在证书列表显示原因，1 小时后重试，也可以点“立即申请”。

| 验证方式 | 谁来完成 | 要求 |
| --- | --- | --- |
| Cloudflare DNS | 面板直接调用 Cloudflare API 添加临时 TXT 记录 | 一个有 Zone.DNS 编辑权限的 API Token；支持通配符 |
| HTTP | 使用这张证书的节点上的 Agent 临时监听 TCP 80 | 域名解析到其中一台节点；80 端口没被其他程序占用 |
| TLS-ALPN | 同上，临时监听 TCP 443 | 域名解析到其中一台节点；443 的 TCP 没被占用（REALITY 占用 443 时不能用） |

HTTP / TLS 验证需要节点配合：还没有启用的服务使用这张证书时，会显示“需要节点配合”，等有服务使用后自动申请。
验证期间 Agent 会自动放行对应端口，验证结束后关闭；端口被占用时会显示是哪个程序。需要 Agent 0.5.37 或更新版本。

## 通配符证书

使用 `*.example.com` 这样的通配符证书时，面板会把节点名转成十六进制作为 SNI 前缀（例如节点 `jp-nb` 使用 `6a702d6e62.example.com`），明文传输的 SNI 里不会直接出现节点名。前缀最长 62 个字符，对应节点名的前 31 个字节，超出部分截断。
请确保对应的域名解析到节点 IP。
