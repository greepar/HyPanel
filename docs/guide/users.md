# 用户与订阅

## 用户组

每个用户属于一个用户组，**组里勾选了哪些服务，组内成员就能用哪些服务**。新建服务时可以自动加入指定的组（默认组默认
开启）。

打开组的「禁止使用代理线路」后，组内成员只能用直连出去的线路：经 HTTP / SOCKS 代理出去的线路（服务的默认线路或附加线路）不会出现在他们的订阅里，节点也不接受他们在这些线路上的连接；一条直连线路都没有的服务整个不提供给他们。节点的 Agent 需要 0.5.39 或更新版本才能按线路区分，更旧的 Agent 上，只要服务有任何一条代理线路，这些成员就用不了这个服务。

## 创建用户

在“用户”页点击“添加用户”：

| 字段 | 说明 |
| --- | --- |
| 用户名 / 密码 | 用户登录面板用，密码至少 6 位 |
| 角色 | 管理员或普通用户；普通用户只能看到自己的订阅和用量 |
| 用户组 | 决定能用哪些服务 |
| 流量上限（GB） | 留空为不限 |
| 流量重置 | 每月某一天（1–28 日，UTC 0 点）自动清零已用流量 |
| 到期时间 | 留空为永久 |

用户卡片上的“重置流量”可以立即清零已用流量，因超额被停用的服务会马上恢复。

::: info
停用、删除、到期或超出流量后，节点会在约 10 秒内移除该用户，正在使用的连接也会断开。
:::

## 订阅链接

每个账户**只能查看和管理自己的订阅链接**：

- 普通用户登录后在“我的订阅”里看到；
- 管理员在“概览”页看到自己的订阅。

订阅是 Clash / Mihomo 格式，适用于 Clash Verge、Mihomo Party、ClashX Meta、Stash 等客户端，可以复制链接、扫码或
一键导入。客户端里会显示剩余流量和到期时间。节点名以节点的国旗和城市开头，后面是节点名称（适合填厂商名，在节点“设置”里修改）：

| 类型 | 格式 | 例子 |
| --- | --- | --- |
| 直连 | 国旗 城市 · 节点名称 协议 | `🇯🇵 东京 · 搬瓦工 Hy2` |
| 直连 IPv6 | 国旗 城市 · 节点名称 协议 [v6] | `🇭🇰 香港 · Bage VLESS [v6]` |
| 经代理出去 | 国旗 城市 · 节点名称 [v6] -> 出口国旗 线路名 | `🇺🇸 洛杉矶 · DMIT -> 🇫🇷 WS130` |

城市由 Agent 根据节点 IP 自动识别（需要 Agent 0.5.40 或更新版本），常见城市显示中文，其余显示英文；识别不到时只显示国旗。箭头后的出口国旗由 Agent 经代理查询出口 IP 得到，每 6 小时刷新一次，查到之前不显示。附加的直连线路会在协议后加上线路名。名称重复时后面会加上 (2)、(3)。

链接泄露时点击“重置链接”：旧链接立即失效，需要用新链接重新导入。

## 分流规则

订阅自带一套参考 ACL4SSR 的分流规则。管理员可以在“设置 → 订阅规则模板”里修改：

- `proxies: ~` 这一行会被替换为用户可用的节点；
- 策略组里的 `- __ALL_PROXIES__` 会展开为全部节点名，`- __DIRECT_PROXIES__`、`- __DIRECT_V6_PROXIES__`、`- __RELAY_PROXIES__` 分别展开为直连、直连 IPv6 和经代理出去的节点。默认模板的“手动切换”就是由这三组组成的；
- 也可以用 Mihomo 的 `include-all: true` + `filter` 按节点名（含国旗）自动归组。
