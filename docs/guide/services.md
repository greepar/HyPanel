# 创建服务

在节点详情的“服务”页点击“添加服务”，选择后端类型。大部分参数会自动生成，一般只需要确认名字即可保存。

| 类型 | 适用场景 | 需要准备 |
| --- | --- | --- |
| Hysteria2 | 基于 QUIC，弱网下速度好 | 一张 TLS 证书（见 [TLS 证书](./certificates)） |
| Xray REALITY | 基于 TCP，伪装成访问大站 | 无，密钥自动生成 |

### 协议与内核

添加服务时先选协议（客户端连接用的协议），有的协议可以再选由哪个**内核**在节点上运行：

| 协议 | 内核 | 说明 |
| --- | --- | --- |
| Hysteria2 | 官方 Hysteria 2 | 默认。支持由内核自己申请 ACME 证书。 |
| Hysteria2 | Xray-core | 与官方服务端对客户端完全一样，额外支持一个端口多条线路；证书需要上传或指定路径，不支持 ACME 自动申请。 |
| VLESS + REALITY | Xray-core | 支持多条线路和转发入口。 |

已有服务可以在编辑里切换同一协议的内核，订阅不变，用户不用更新；保存后服务用新内核重启一次。使用 Xray 内核运行 Hysteria2 需要节点 Agent 0.5.34 或更新版本。

保存后服务会立刻下发到节点，并自动对所在用户组的用户开放。

## 常用设置

- **监听端口**：默认随机选择节点上的空闲端口，也可以手动填写。
- **连接地址**：订阅使用节点公网 IP 和监听端口。
- **IPv6 入口**：Agent 会自动探测节点的公网 IPv6。探测到时，订阅里每个服务会多出一条名称带「IPv6」的入口，直连节点的 IPv6 地址（经过中转的服务用中转节点的 IPv6）；监听地址为 `0.0.0.0` 的服务会同时监听 IPv4 和 IPv6。节点的 IPv6 连续一天探测不到就会从订阅中移除。节点有公网 IPv6 时，服务编辑里会出现「IPv6」一栏：关掉「提供 IPv6 入口」后订阅不再提供 IPv6 入口，这个开关只影响订阅，不会重启服务；打开「禁用 IPv6 出口」后直连出站只用 IPv4，网站看到的是节点的 IPv4 地址，走代理的线路不受影响，需要 Agent 0.5.36 或更新版本。Agent 只采用节点网卡上真实存在、能从外部连回来的 IPv6，装了 Cloudflare WARP 等隧道的节点不会误报隧道的出口地址。以前版本设置过自定义连接地址的服务只保留自定义的那一个入口。纯 IPv6 节点也可以使用。云厂商安全组需要自行放行 IPv6 端口。
- **密码**：输入框右侧的眼睛图标可以查看已保存的密码。
- **REALITY 伪装目标**：默认从一组常见大站中随机选择，也可以手动指定。
- **密钥与标识**默认收起，展开后可以查看和轮换。
- **后端**一栏显示当前、目标和最新版本，可以一键更新，也可以开关自动更新。

## 线路与出口

服务编辑里的“线路”决定流量从哪里离开。每条线路可以直连，也可以改走一个外部代理（例如租用的 Webshare 住宅代理），
这样网站看到的是代理的 IP，而不是节点本身的 IP。选择出口类型后填写代理地址、端口、用户名和密码：

| 类型 | 说明 |
|---|---|
| HTTP 代理 | 通过 HTTP `CONNECT` 访问目标，只支持 TCP。 |
| HTTPS 代理 | 与 HTTP 代理相同，但节点到代理服务器的连接用 TLS 加密，并校验代理服务器的证书。 |
| SOCKS5 代理 | 是否支持 UDP 取决于代理服务器。 |

注意：

- 所有出站流量都会经过这个代理；**代理不可用时连接直接失败，不会回退到节点直连**，避免泄露节点自己的 IP。
- 目标域名交给代理解析，不使用节点的 DNS。
- HTTP 和 HTTPS 代理不支持 UDP，QUIC、部分游戏和 UDP DNS 会被丢弃。
- 类型、地址、端口必须一起填写；只填一部分会在保存时被拒绝。填写了密码就必须同时填写用户名。
- 密码和其他密钥一样在列表中隐藏，点击眼睛图标才会显示。
- 订阅里的国旗会显示代理出口所在的国家：Agent 会经由代理查询出口 IP，每 6 小时刷新一次；查询失败时仍显示节点所在国家的国旗。
- 这和下面的“转发入口”方向不同：线路出口改变的是服务**出去**时的 IP，转发入口改变的是客户端**进来**时连接的地址。

### 一个端口多条线路（Xray 内核）

Xray 内核的服务（REALITY 和 Hysteria2）可以点“添加线路”挂多条线路。所有线路共用同一个端口和伪装（REALITY 的伪装目标与密钥、Hysteria2 的证书与混淆），节点上只运行一个 Xray 进程；
每条线路在订阅里是一个独立节点（名称为“国旗 国家代码 · 线路名 · From 节点”），用户用不同的 UUID 连接，Xray 按 UUID 把流量送到这条线路的出口。

- 适合同一台节点要提供多个出口国家的情况，例如一条直连、一条走法国住宅代理。
- 每个用户的流量统计把所有线路加在一起，记在这个服务下。
- 删除一条线路后，用户更新订阅就不会再看到它；之前分发的这条线路的 UUID 立即失效。
- 节点的 Agent 需要 0.5.34 或更新版本，旧版本的节点保存时会被提示先更新 Agent。

## 转发入口

Xray REALITY 服务可以由另一台节点的 Agent 转发 TCP 端口：客户端连接入口节点，服务仍运行在当前节点，网站看到的是当前节点的出口 IP。
详见[转发入口](./relay)。

## Hysteria2 端口跳跃

在“端口跳跃”里填写端口范围或端口列表，例如 `20000-30000` 或 `443,8443,20000-20100`。客户端会在这些端口之间跳换，
减少单端口被限速的影响。

::: warning 注意
- 只支持 Linux 节点，并且需要用新版安装命令安装的 Agent（具备 `CAP_NET_ADMIN` 权限）。
- 云服务商的安全组 / 防火墙要放行对应的 UDP 端口范围。
:::

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 运行中 | 服务正常 |
| 重启退避 | 服务启动失败，Agent 正在间隔重试；到节点“日志”页查看原因，常见的是端口冲突 |
| 已停用 | 在面板里手动停用了 |
