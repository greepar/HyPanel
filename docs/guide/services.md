# 创建服务

在节点详情的“服务”页点击“添加服务”，选择后端类型。大部分参数会自动生成，一般只需要确认名字即可保存。

| 类型 | 适用场景 | 需要准备 |
| --- | --- | --- |
| Hysteria2 | 基于 QUIC，弱网下速度好 | 一张 TLS 证书（见 [TLS 证书](./certificates)） |
| Xray REALITY | 基于 TCP，伪装成访问大站 | 无，密钥自动生成 |
| Xray Shadowsocks 2022 | 简单通用 | 无，密钥自动生成 |

保存后服务会立刻下发到节点，并自动对所在用户组的用户开放。

## 常用设置

- **监听端口**：默认随机选择节点上的空闲端口，也可以手动填写。
- **连接地址**：默认使用节点公网 IP 和监听端口；如果用了域名或端口转发，可以在服务编辑里自定义地址、端口和 SNI。
- **密码**：输入框右侧的眼睛图标可以查看已保存的密码。
- **REALITY 伪装目标**：默认从一组常见大站中随机选择，也可以手动指定。

## Hysteria2 端口跳跃

在“端口跳跃”里填写端口范围或端口列表，例如 `20000-30000` 或 `443,8443,20000-20100`。客户端会在这些端口之间跳换，
减少单端口被限速的影响。

::: warning 注意
- 只支持 Linux 节点，并且需要用新版安装命令安装的 Agent（具备 `CAP_NET_ADMIN` 权限）。
- 云服务商的安全组 / 防火墙要放行对应的 UDP 端口范围。
:::

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 运行中 | 服务正常 |
| 重启退避 | 服务启动失败，Agent 正在间隔重试；到节点“日志”页查看原因，常见的是端口冲突 |
| 已停用 | 在面板里手动停用了 |
