# 创建服务

在节点详情的“服务”页点击“添加服务”，选择后端类型。大部分参数会自动生成，一般只需要确认名字即可保存。

| 类型 | 适用场景 | 需要准备 |
| --- | --- | --- |
| Hysteria2 | 基于 QUIC，弱网下速度好 | 一张 TLS 证书（见 [TLS 证书](./certificates)） |
| Xray REALITY | 基于 TCP，伪装成访问大站 | 无，密钥自动生成 |
| Xray Shadowsocks 2022 | 简单通用 | 无，密钥自动生成 |

保存后服务会立刻下发到节点，并自动对所在用户组的用户开放。

## 常用设置

- **监听端口**：默认随机选择节点上的空闲端口，也可以手动填写。
- **连接地址**：默认使用节点公网 IP 和监听端口；如果用了域名或端口转发，可以在服务编辑里自定义地址、端口和 SNI。
- **密码**：输入框右侧的眼睛图标可以查看已保存的密码。
- **REALITY 伪装目标**：默认从一组常见大站中随机选择，也可以手动指定。

## 上游代理

Xray REALITY、Xray Shadowsocks 和 Hysteria2 服务都可以让出站流量改走一个外部代理（例如租用的 Webshare 住宅代理），
这样网站看到的是代理的 IP，而不是节点本身的 IP。在服务编辑里的“上游代理”中选择类型并填写地址、端口、用户名和密码：

| 类型 | 说明 |
|---|---|
| HTTP 代理 | 通过 HTTP `CONNECT` 访问目标，只支持 TCP。 |
| HTTPS 代理 | 与 HTTP 代理相同，但节点到代理服务器的连接用 TLS 加密，并校验代理服务器的证书。 |
| SOCKS5 代理 | 是否支持 UDP 取决于代理服务器。 |

注意：

- 所有出站流量都会经过这个代理；**代理不可用时连接直接失败，不会回退到节点直连**，避免泄露节点自己的 IP。
- 目标域名交给代理解析，不使用节点的 DNS。
- HTTP 和 HTTPS 代理不支持 UDP，QUIC、部分游戏和 UDP DNS 会被丢弃。
- 类型、地址、端口必须一起填写；只填一部分会在保存时被拒绝。填写了密码就必须同时填写用户名。
- 密码和其他密钥一样在列表中隐藏，点击眼睛图标才会显示。
- 这和下面的“转发入口”方向不同：上游代理改变的是服务**出去**时的 IP，转发入口改变的是客户端**进来**时连接的地址。

## 转发入口

Xray REALITY 服务可以由另一台节点的 Agent 转发 TCP 端口：客户端连接入口节点，服务仍运行在当前节点，网站看到的是当前节点的出口 IP。
详见[转发入口](./relay)。

## Hysteria2 端口跳跃

在“端口跳跃”里填写端口范围或端口列表，例如 `20000-30000` 或 `443,8443,20000-20100`。客户端会在这些端口之间跳换，
减少单端口被限速的影响。

::: warning 注意
- 只支持 Linux 节点，并且需要用新版安装命令安装的 Agent（具备 `CAP_NET_ADMIN` 权限）。
- 云服务商的安全组 / 防火墙要放行对应的 UDP 端口范围。
:::

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 运行中 | 服务正常 |
| 重启退避 | 服务启动失败，Agent 正在间隔重试；到节点“日志”页查看原因，常见的是端口冲突 |
| 已停用 | 在面板里手动停用了 |
